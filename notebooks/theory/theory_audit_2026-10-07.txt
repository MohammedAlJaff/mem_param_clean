SCIENTIFIC QUALIFICATIONS TO KEEP
1. Delta G measures a change in population-minus-training velocity MSE.
   It is not f_mem, a probability, or a generated-copying rate.
2. Linear predictors depend on the clean dataset only through X^T X/n.
   The mechanism is fitting sample second moments.
3. Native zero initialization gives initial velocity maps -I/(1-t), I/t, 0.
   Matching initial velocities makes the linear trajectories identical.
4. At t=1/2 for N(0,I), zero velocity is population-optimal. Initial velocity
   MSEs are 4,4,2 for x,epsilon,v. Show population error alongside the gap.
5. The cubic expected epsilon gap requires zero native initialization and
   linear features. Nonzero Gaussian initialization adds a linear term.
   Nonlinear features can also add a linear expected epsilon term.
6. Pure finite tanh features define different decoded velocity function
   classes because x/epsilon conversion includes a linear input term.
   Do not transfer the linear common-limit claim to this RFN.
7. The model studies one fixed t, not a time-conditioned network or a full
   generative trajectory. It does not establish a universal target ranking.

The first five epsilon means in the existing log-log panel are nonpositive
and cannot appear on its log y axis. This is finite-ensemble variation,
